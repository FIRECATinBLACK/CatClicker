# Security policy

Do not publish sensitive vulnerability details in a public issue.

Security issues include unintended command execution, unsafe macro parsing, unexpected network communication, permission escalation, input injection outside requested playback, or disclosure of recorded input. A macro causing CatClicker itself to run commands is a security issue. Input deliberately replayed into a terminal and interpreted by that terminal is a different trust boundary.

GitHub private vulnerability reporting is available for this repository. Report sensitive security vulnerabilities through that private reporting mechanism.

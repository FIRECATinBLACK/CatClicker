# Privacy

CatClicker does not send recorded input anywhere. It has no telemetry, analytics, advertising, crash upload, update checker, or network client. Macro files remain local unless shared and may contain key codes, button numbers, scroll deltas, timestamps, and mouse coordinates.

The shareable debug report uses an allowlist. It includes versions, build capabilities, OS product and session type, selected backends, safe display geometry, access state, aggregate health, and CatClicker warnings. It excludes usernames, hostnames, home and file paths, device names or serials, environment dumps, macro names or contents, keys, typed text, mouse coordinates, clipboard data, window titles, process lists, and event-level logs. The full report is previewed before copying.

Event tracing flags can expose input activity. Do not enable them while entering sensitive data or post their output publicly. The GitHub button performs no HTTP request in CatClicker. It asks the desktop browser to open a fixed URL after a click.
